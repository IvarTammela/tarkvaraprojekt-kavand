# Koolisöökla toitude tellimise süsteem: kavand

See repositoorium sisaldab kavandust, mis näitab, kuidas valmistuksin seda rakendust päriselt arendama. Rakendust ennast ei ole programmeeritud.

Idee: õpilased tellivad koolisöökla toidu veebist ette, söökla näeb tellimusi ja saab ülevaate päeva toitudest.

| Osa | Fail | Sisu |
|---|---|---|
| 1. Arendusprotsess | [docs/1-arendusprotsess.md](docs/1-arendusprotsess.md) | etapid, mudelite võrdlus, valitud mudel, nõuete muutmine |
| 2. Metoodika | [docs/2-metoodika-ja-sprint-1.md](docs/2-metoodika-ja-sprint-1.md) | Scrumi valik, esimene arendusperiood |

| 4. Arhitektuur | [docs/4-arhitektuur.md](docs/4-arhitektuur.md) + [diagrams/arhitektuur.puml](diagrams/arhitektuur.puml) | skeem, andmevoog, alternatiiv |
| 5. Versioonimine | [docs/5-versioonid.md](docs/5-versioonid.md) | SemVer plaan ja näited |

## Tööde haldamine

Backlog on GitHubi Issues’is: https://github.com/IvarTammela/tarkvaraprojekt-kavand/issues
Issue’d on märgistatud prioriteedi järgi (`prioriteet: 1` … `prioriteet: 3`) ja kuuluvad sprinti 1 (`sprint-1`), kui on valitud esimesse arendusperioodi.

## Kuidas dokumente lugeda

Kõik dokumendid on Markdown-vormingus ja loetavad GitHubis. Skeemi lähtefail on tekstipõhine PlantUML (`.puml`), seda saab muuta ilma joonistusprogrammita ja avada näiteks PlantUML serveris või VS Code laiendusega.
